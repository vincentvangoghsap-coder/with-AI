# セキュリティ方針

## このプロジェクトについて
Y Security Labは、Webアプリケーションの脆弱性を学ぶためのプロジェクトです。
現在は設計段階です。今後、意図的な脆弱性を含むアプリと、その修正版を実装する予定です。
このリポジトリは、実運用のSNSとして利用することを想定していません。

## 脆弱版と修正版
- `apps/vulnerable/y_app/`：学習対象として、意図的な脆弱性を含むアプリ。
- `apps/fixed/y_app/`：学習対象の脆弱性に対して、修正を実施したアプリ。
`fixed` という名称は、アプリ全体の安全性を保証するものではありません。対策済みの範囲と検証結果は、各学習資料・分析レポートに記載します。
実装済みの意図的な脆弱性と再現条件は `labs/` に、原因・修正内容・検証結果は `docs/reports/` に記録します。

## 実行時の注意
- ローカルの学習環境でのみ実行してください。
- インターネットや共有ネットワークに公開しないでください。
- ローカル専用の環境を使用し、外部公開用のトンネルなどを接続しないでください。
- 架空のユーザー情報や投稿データを使用してください。
- 普段使用しているパスワード、実際のAPIキー、個人情報を入力しないでください。
- 攻撃の再現には、学習用のブラウザプロファイルを使用することを推奨します。
- 実行時のデータベース、秘密情報、認証情報を含むログなどをGitHubに公開しないでください。

再現手順やコードは、このプロジェクトの自作アプリでの学習を目的としています。第三者のシステムに対して、許可なく使用しないでください。

## 問題を見つけた場合

### 意図的な脆弱性
`labs/` に記載された条件で発生する、学習対象の脆弱性については、通常の脆弱性報告は不要です。
再現手順の誤り、説明不足、想定と異なる動作については、Issueでお知らせください。

### 想定外の問題
次のような問題は報告対象です。
- 修正版で、対策済みとされる攻撃が成立する。
- 記載されていない脆弱性が見つかる。
- 起動手順や設定によって、意図せず外部からアクセス可能になる。
- 秘密情報や実在する個人情報が含まれている。

公開して差し支えない問題は、Issueに以下を記載してください。
- 対象のバージョンまたはコミット
- 実行環境
- 再現手順
- 期待した動作と実際の動作
- 想定される影響

秘密情報、個人情報、第三者に影響する情報は、公開Issueに貼り付けないでください。
機密性のある問題の非公開報告窓口は、現時点では未設定です。
