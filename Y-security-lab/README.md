# Y Security Lab
X（旧Twitter）から着想を得たSNS「Y」を題材に、Webアプリケーションの脆弱性の仕組みと対策を学ぶプロジェクトです。
脆弱性を含むアプリと修正版を作成し、攻撃の再現→原因の分析→修正→再検証の過程を記録します。
> 現在は設計段階です。アプリ、攻撃の再現手順、自動テストは未実装です。以下は実装予定の内容です。

## 目的
- Webアプリケーションの脆弱性が発生する仕組みを理解する。
- 自作のアプリに対して攻撃を再現し、成立条件と影響を確認する。
- 原因に対応した修正を行い、その理由を説明できるようにする。
- 修正後に攻撃が成立しないことと、正常な機能が動作することを検証する。
- 調査・修正・検証の過程を、第三者が確認できる形で残す。

## アプリの概要
Yは、次の機能を持つ小規模なSNSを予定しています。
- ユーザー登録・ログイン・ログアウト
- テキスト投稿とタイムラインの表示
- プロフィールの表示・編集
- 本人のみが閲覧できる非公開投稿
- アカウント設定の変更
最初は登録・ログイン機能とSQLインジェクションの検証から着手し、段階的に機能と学習対象を追加します。

## 学習対象
| 脆弱性・問題 | 検証予定の内容 | 主な修正方針 |
|---|---|---|
| SQLインジェクション | ログイン処理への不正な入力による認証回避 | パラメータ化クエリ |
| XSS | 投稿内容を通じた意図しないスクリプトの実行 | 出力先に応じたエスケープ |
| IDOR（オブジェクト単位の認可不備） | 他人の非公開投稿の閲覧やプロフィールの不正な編集 | サーバー側の認可チェック |
| CSRF | 別のページを経由した意図しない設定変更 | CSRFトークンの検証など |
| 不適切なパスワード保存 | 保存方式によるリスクの比較 | 適切なパスワードハッシュ化 |
学習対象や実装方法は、開発の進行に応じて見直します。

## リポジトリ構成
以下は予定している主な構成です。
```
y-security-lab/
├── apps/
│   ├── vulnerable/
│   │   └── y_app/       # 意図的な脆弱性を含むアプリ
│   └── fixed/
│       └── y_app/       # 対象の脆弱性を修正したアプリ
├── labs/                # 脆弱性ごとの説明・再現手順・再現用コード
├── tests/
│   ├── functional/      # 正常な機能の動作確認
│   └── security/        # 脆弱性の再現確認と修正後の検証
├── fixtures/            # 架空のユーザー・投稿データ
├── scripts/             # データ初期化などの補助ツール
├── docs/
│   ├── reports/         # 原因・影響・修正内容・検証結果の分析
│   ├── evidence/        # スクリーンショットなどの検証記録
│   ├── learning-log.md  # 学習中の仮説・観察・判断
│   └── ai-usage.md      # AIの利用範囲と本人の担当内容
├── AGENTS.md            # AIによる開発支援の作業ルール
├── SECURITY.md          # 学習環境の扱いと不具合の報告方針
└── README.md
```

脆弱版と修正版は、同じ機能・操作・初期データを用意し、コードと動作の違いを比較できるようにします。データベースはそれぞれ分離します。
なお、`fixed` は対象とした脆弱性の修正版を意味し、アプリ全体に脆弱性が存在しないことを保証するものではありません。

## 学習・検証の進め方
1. 対象機能の正常な動作と、許可される操作を定義する。
2. 脆弱版で攻撃を再現し、結果を記録する。
3. 攻撃が成立する原因と影響を分析する。
4. 修正版に対策を実装する。
5. 同じ攻撃が成立しないことを確認する。
6. 正常な操作が引き続き成功することを確認する。
7. 再現手順、修正差分、検証結果を文書にまとめる。
自動テストでは、脆弱版で意図した攻撃が成立することと、修正版で防げることを、それぞれ期待結果として検証します。必要に応じてブラウザによる手動検証も行います。

## AIの利用について
AIを利用してアプリの雛形を作成し、開発中の説明やレビュー、テスト作成などの支援を受ける方針です。
本人は動作確認、攻撃の再現、修正、分析を中心に担当します。AIが生成した内容も確認し、利用範囲と本人が検証した内容を `docs/ai-usage.md` に記録します。

## 実行環境と利用範囲
脆弱版は、ローカルの学習環境でのみ実行することを前提とします。インターネットや共有ネットワークに公開せず、実在する個人情報や普段使用しているパスワードは使用しません。
攻撃の再現は、このプロジェクトの自作アプリを対象とします。第三者のサービスに対して、許可なく実行しないでください。
実行時のデータベース、秘密情報、セッション情報などはGitの管理対象から除外します。
